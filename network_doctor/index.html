Uses Cloudflare’s global anycast edge. Network routing chooses an edge location; this page cannot promise a specific city such as Darbhanga, Patna or Kolkata.

Custom test server (administrator only)
Enter the base HTTPS URL of a server you own or have permission to use, for example https://speedtest.example.com. The current script expects these routes:

  • GET /__down?bytes=12000000 — return the requested number of bytes as a response body.
  • POST /__up — accept and consume the uploaded request body; return a successful HTTP status.
  • Enable CORS for the SancharEasy website origin. Support OPTIONS preflight where needed and allow GET, POST and Content-Type.
  • Use HTTPS, verify the endpoint from real browsers, apply abuse/rate limits, and provision enough bandwidth so one test does not saturate the server.

Why not list all Ookla servers?
Ookla’s server list belongs to its own test network. Those servers run an Ookla-specific server daemon and are operated by participating hosts; their presence in Ookla does not mean they expose a generic, reusable endpoint for this page. A trustworthy multi-city selector needs endpoints we can lawfully use, test, and maintain.

Recommended for the public launch: leave Automatic selected and hide the custom option from ordinary visitors until you have your own verified server registry.

Frequently asked questions

What the measurements mean—and where their limits are.

Why can my result differ from my ISP plan?

Wi-Fi interference, device performance, Ethernet port negotiation, background traffic, VPNs, the test endpoint and routing can all affect results. Run a repeat test over Ethernet with other traffic paused before concluding that the ISP is under-delivering. Plan rates may be advertised in Mbps and may have terms about typical or peak speeds.

Can this page tell me my exact FTTH optical power or OLT congestion?

No. A browser cannot directly read ONT optical receive power, OLT/PON utilisation, BNG counters or physical-layer alarms. Those require authorised access to the ONT/router or the operator’s network-management systems. This tool can help collect symptoms and end-to-end evidence to guide the next check.

Does the server selector let me choose Patna, Darbhanga or a specific ISP server?

Not in the default configuration. Cloudflare uses a global anycast network and the physical location serving a request is not guaranteed by this page. A genuine city/operator selector requires a verified registry of independent test servers with stable endpoints, sufficient capacity, permission to test, and working CORS. Do not label a server by city unless the endpoint owner verifies it.

Is the latency measurement the same as a ping test?

It is an HTTP timing-based estimate to the test endpoint, not ICMP ping. It includes browser scheduling, TLS/network overhead and server response time. A browser cannot ordinarily issue ICMP ping or directly ping your home gateway. The downloadable Windows script can run local ping and traceroute tests.

Why does the report say “suspected” instead of naming a fault?

Several different faults can create similar symptoms. For example, a speed plateau near 94 Mbps can be consistent with a 100 Mbps Ethernet link, but it does not prove that is the cause. A responsible diagnosis lists likely explanations and the next test that can distinguish them.

Will my public IP be included in the report?

Only if you opt into the lookup and separately check the report option to include it. An IP address can be sensitive information, so review the report before sharing it with anyone.
