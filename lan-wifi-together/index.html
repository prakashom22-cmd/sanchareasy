Use office LAN and WiFi together

Keep your internal network (CDR, CPAN, etc.) on the LAN cable and the internet on WiFi, at the same time. Fill in the details, download the script, run it as administrator.

Ready. Download, then right-click the file and choose Run as administrator.

How it works, and when it will not

Both adapters offer a default route, so Windows sends all traffic through one of them. The script gives WiFi the better priority for the internet and adds fixed routes so only your internal addresses go through the LAN. Nothing leaves your computer: this page runs in your browser and only builds a text file.


It will not work if office policy blocks a second active adapter, if a VPN client forces its own routes, or if you do not have administrator rights. To go back, run the undo script.
