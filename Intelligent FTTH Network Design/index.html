Parameter guide

Inputs

PON technology / receiver limits
Sets the standard receiver limits. GPON Class B+ and C+ are optical classes (power budget about 28 dB and 32 dB). Pick Custom for XGS-PON or other equipment and type your datasheet values.
OLT launch power (dBm)
Optical power the OLT PON port transmits into the fibre. Everything downstream is this number minus losses. Use your OLT SFP/transceiver value, not the maximum of the class.
ONT min sensitivity (dBm)
Weakest signal the ONT can still receive without errors. If received power falls below this, the link fails.
ONT max input / overload (dBm)
Strongest signal the ONT can tolerate. A short, lightly split link can exceed it and needs an attenuator.
Fibre loss, downstream (dB/km)
Attenuation of the fibre at the downstream wavelength (1490 nm for GPON). Loss = length in km x this value.
Fibre loss, upstream (dB/km)
Same, at the upstream wavelength (1310 nm for GPON). Used only for the upstream check.
Connector loss (dB each)
Loss at each mated connector pair. The model counts 2 + 2 per splitter stage.
Splice loss (dB each)
Loss per fusion splice. The model counts 2 per splitter stage plus 1 per km of cable.
Design margin (dB)
Safety allowance for ageing, repairs, temperature and measurement error. A path passes only if received power is at least this far above the sensitivity.
Drop length (m)
Cable from the last splitter to the customers. The last splitter is placed this far before each cluster.
Max ONTs per PON port
Most subscribers one PON port will serve (GPON allows up to 128 logically; many operators use 64). If the design exceeds it, you need more PON ports.
ONT Tx power, upstream (dBm)
Power the ONT transmits toward the OLT. Optional: needed with OLT Rx sensitivity for the upstream check.
OLT Rx sensitivity (dBm)
Weakest upstream signal the OLT can receive. Optional, with ONT Tx.
Cable cost per fibre-metre
Your price for one metre of one fibre. Optional. Together with splitter prices it gives a capital cost. Nothing is pre-filled.
Design basis
A sizes for today's customers only, B adds half the expected growth, C sizes for the full future count.
Priority
Changes the scoring weights: balanced, lowest initial cost, highest optical margin, or most spare capacity.

Results

Path loss
Total dB lost from the OLT to the ONT: fibre + splitters + connectors + splices.
Rx power
Power arriving at the ONT = launch power minus path loss.
Margin
Rx power minus sensitivity. It is the safety room left before the link fails.
PASS / LOW MARGIN / BELOW SENSITIVITY / OVERLOAD / CANNOT VALIDATE
PASS: margin at least the design margin. LOW MARGIN: positive but under the design margin. BELOW SENSITIVITY: link fails. OVERLOAD: signal too strong. CANNOT VALIDATE: receiver limits missing, so no pass is given.
Two stage 1:a @s m + 1:b
A first splitter (ratio 1:a) placed s metres from the OLT, feeding second splitters (1:b) placed near each customer cluster. Single stage means one splitter at the OLT.
Fibre-m (fibre-metres)
Sum of every fibre run in the design. It is a cost proxy: more fibre-metres means more cable.
Splitters
Total splitter count, a proxy for enclosures, joints and fault points.
Spare / Output capacity
Capacity is the total splitter ports installed. Spare is capacity minus the customers served.
Stage-1 outputs insufficient
Each second-stage splitter needs its own first-stage port. This error means more second-stage splitters are needed than the first splitter has outputs.
Score
Weighted blend of margin, fibre-metres, splitter count and spare ports among feasible candidates. Higher is better. Rejected candidates get no score.
Ideal vs specified splitter loss
Ideal = 10 x log10(N) dB. Specified is the real datasheet value, which is higher and is the one used.
Unverified specs
Number of splitter ratios still using generic default losses. Tick Verified in the library once you enter datasheet values.
